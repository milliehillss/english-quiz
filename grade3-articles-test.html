Тема: артикли a / an и указательные слова this / that / these / those.
Выбери ответ — проверка и объяснение появятся сразу под вопросом.

Вспомни правило перед началом

1. Артикли a / an
a ставим перед словом, которое начинается с согласного звука: a bus, a toy, a box.
an ставим перед словом, которое начинается с гласного звука: an apple, an orange, an umbrella.

2. Указательные слова this / that / these / those
this — один предмет рядом: this toy.
that — один предмет далеко: that bus.
these — несколько предметов рядом: these boxes.
those — несколько предметов далеко: those bikes.

Как запомнить?
This / that — один предмет. These / those — несколько предметов.
This / these — рядом. That / those — далеко.

1. Выбери a или an

Выбери правильный вариант. Помни: an ставим перед гласным звуком, а a — перед согласным.

2. Выбери this, that, these или those

This / these — предметы рядом. That / those — предметы далеко. This / that — один предмет. These / those — несколько предметов.
